Concept 1

What you are building

Everything on Linux is a file or a directory with an owner and a permission mode. This is the target layout. The numbers are the modes the checker will expect.

app/—The application root. ├── bin/—Executable scripts live here. │ └── healthcheck.sh750You run it; your group may run it; nobody else. ├── config/—Settings, often containing secrets. │ └── app.env600Owner read/write only. Secrets are never world-readable. ├── logs/750Others cannot list or read logs. │ └── app.log—Empty file, created with touch. └── current-config → config/app.envlinkA symbolic link (signpost) to the real file.

One command creates every directory: mkdir -p app/{bin,config,logs}. The braces expand to three paths and -p makes it safe to run twice.

Concept 2

Permission calculator

Each of the three digits is a sum: read = 4, write = 2, execute = 1. Toggle the bits, pick a preset, or type a mode to see what it means.

Concept 3

Symbolic links

A symlink stores a path, not data. Deployment tools keep several releases side by side and repoint current to switch between them in one step. Use a relative target so the link still works if the whole folder moves.

Swipe the diagram sideways to see all of it.

$ cd app && ln -s config/app.env current-config $ ls -l current-config lrwxrwxrwx 1 you you 14 Oct 15 12:00 current-config -> config/app.env
