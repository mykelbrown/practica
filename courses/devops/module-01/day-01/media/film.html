6 · Fail fast

#!/usr/bin/env bash
set -euo pipefail

-e

Exit as soon as any command fails.

cp missing.txt /tmp
# script stops here
-u

Using an unset variable is an error.

rm -rf "$DIRR/"
# typo caught, nothing deleted
-o pipefail

A pipe fails if any part fails.

false | sort
# exit 1, not 0
